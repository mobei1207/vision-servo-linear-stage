# vision-servo-linear-stage

> 基于 STM32F103C8T6 与 Python/OpenCV 的视觉伺服直线运动平台，DM542 驱动 57 步进电机，串口通信实现视觉闭环自动对准。

## 项目简介

本项目为机械电子工程专业综合设计，开发一套基于视觉伺服控制的直线运动平台。系统采用上下位机主从控制架构：

- **上位机**：PC + Python + OpenCV，通过 USB 工业相机采集图像，识别红色目标，计算目标质心与画面中心的像素偏差，经串口发送运动指令。
- **下位机**：STM32F103C8T6，接收串口指令，输出 PWM 脉冲与方向信号，控制 DM542 驱动 57 步进电机，经 7:1 减速器带动 ECB80D 同步带模组，实现 500mm 行程内的直线运动。
- **闭环逻辑**：视觉检测 → 偏差计算 → 串口指令 → 电机运动 → 平台移动 → 视觉再检测，形成视觉闭环自动对准。

## 功能

- **初始化回零**：上电后电机以 3 档低速反转，触发负限位 PB10 后停止，位置变量清零。
- **手动点动**：W 正转，S 反转，空格停止，0~9 调节速度档位。
- **急停保护**：E 键急停，电机立即停止，再次按 E 解除。
- **限位安全保护**：PB10 负限位/零点，PB11 正限位，中断 + 主循环双重保护。
- **视觉识别**：HSV 颜色空间阈值分割，形态学滤波，轮廓提取，红色目标质心计算。
- **自动对准**：目标质心与画面中心偏差超过死区（15 像素）时，自动发送运动指令；空闲 1 秒后自动进入自动对准模式，速度固定 3 档。
- **串口通信**：4 字节固定帧，115200bps，帧头 0xAA，命令码 + 数据 + 校验和。
- **位置计数**：TIM1 更新中断中根据方向标志对位置变量递增或递减。

## 通信协议

上下位机采用固定 4 字节帧格式：

```
┌────────┬────────┬────────┬──────────┐
│  0xAA  │  CMD   │  DATA  │ CHECKSUM │
│  帧头  │  命令码 │ 数据   │   校验和  │
└────────┴────────┴────────┴──────────┘
```

- **帧头**：固定 `0xAA`
- **命令码**：见下表
- **数据**：速度档位 1~10，或 `0x00`
- **校验和**：`(0xAA + CMD + DATA) & 0xFF`

### 命令码定义

| CMD | 功能 | DATA | 说明 |
|-----|------|------|------|
| 0x01 | 正转 | 1~10 | 速度档位 |
| 0x02 | 反转 | 1~10 | 速度档位 |
| 0x03 | 停止 | 0x00 | 关闭 PWM |
| 0x04 | 急停 | 0x00 | 立即停止 |
| 0x05 | 调零 | 0x00 | 回零状态机 |

### 指令示例

| 功能 | 完整指令 (HEX) | 校验和 |
|------|----------------|--------|
| 正转 1 档 | `AA 01 01 AC` | 0xAC |
| 正转 5 档 | `AA 01 05 B0` | 0xB0 |
| 正转 10 档 | `AA 01 0A B5` | 0xB5 |
| 反转 5 档 | `AA 02 05 B1` | 0xB1 |
| 停止 | `AA 03 00 AD` | 0xAD |
| 急停 | `AA 04 00 AE` | 0xAE |
| 调零 | `AA 05 00 AF` | 0xAF |

## 调试记录

### 调试工具

- **FlyMcu**：STM32 串口下载程序
- **SSCOM**：串口助手，发送十六进制指令，验证上下位机通信
- **万用表**：测量 24V、5V、3.3V 供电
- **示波器**：测量 PA8 PWM 波形

### 调试步骤

1. **下位机独立调试**：用 SSCOM 发送 `AA 05 00 AF` 调零，`AA 01 05 B0` 正转，`AA 02 05 B1` 反转，`AA 03 00 AD` 停止，`AA 04 00 AE` 急停。
2. **上位机独立调试**：运行 Python 程序，用红色物体测试 HSV 识别与质心标记。
3. **联调**：上下位机同时上电，测试手动、自动、急停、限位。

### 问题与解决

| 序号 | 问题 | 原因 | 解决 |
|------|------|------|------|
| 1 | 电机不转，驱动器无反应 | PUL+ 与 DIR+ 并联接 +5V 处虚焊 | 重新焊接 |
| 2 | 电机方向与预期相反 | 方向逻辑反相 | 交换电机 A+ 与 A- |
| 3 | 调零完成后电机仍然缓慢转动 | `PWM_Stop()` 未关闭 `TIM_CtrlPWMOutputs` | 补充关闭主输出 |
| 4 | 自动对准方向与期望相反 | 上位机 `dx > 0` 时错误发送正转 | 修正为 `dx > 0` 发反转 |
| 5 | 手动按键控制被自动模式频繁打断 | 手动按键后未重置空闲计时器 | 手动分支重置计时器 |
| 6 | 急停后状态混乱，无法恢复正常控制 | 解除急停时未重置状态标志位 | 重置 `last_stop_sent`、`mode`、`manual_stopped` |
| 7 | 自动对准时电机频繁启停，产生异响 | 每帧都发送指令，方向频繁切换 | 记录上次方向，调用频率降至 10Hz |
| 8 | 红色阈值在自然光照变化时识别不稳定 | HSV 阈值受光照影响 | 形态学滤波 + 缩小阈值 + 室内遮光 |

## 运行说明

### 上位机

```bash
cd code/upper_computer
pip install -r requirements.txt
python main.py
```

**操作说明：**

| 按键 | 功能 |
|------|------|
| W | 正转 |
| S | 反转 |
| 空格 | 停止 |
| E | 急停/解除急停 |
| Z | 调零 |
| 0~9 | 速度档位 |
| Q | 退出 |

空闲 1 秒后自动进入自动对准模式，速度固定 3 档。

### 下位机

1. 用 Keil MDK 打开 `code/lower_computer/` 下的工程文件。
2. 编译生成 `.hex` 文件。
3. 用 FlyMcu 通过串口下载到 STM32F103C8T6。
4. 上电后自动进入回零状态，等待上位机指令。

### 串口调试

用 SSCOM 发送十六进制指令：

```
AA 05 00 AF    # 调零
AA 01 05 B0    # 正转 5 档
AA 02 05 B1    # 反转 5 档
AA 03 00 AD    # 停止
AA 04 00 AE    # 急停
```

## 不足与改进方向

1. **开环驱动**：未配备编码器，位置反馈仅靠脉冲计数，无法补偿皮带弹性变形和机械间隙。后续可增加 E6B2 编码器，构成全闭环位置控制，引入 PI 调节。
2. **视觉识别鲁棒性**：基于 HSV 阈值分割，对环境光照变化敏感。后续可引入 YOLO 等深度学习目标检测算法。
3. **通信带宽**：串口速率有限，限制视觉反馈周期。后续可采用 USB 虚拟串口或以太网。
4. **机械精度**：同步带传动存在弹性变形，高速时可能跳齿。后续可优化张紧机构或改用滚珠丝杠。
