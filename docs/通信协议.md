


# 视觉伺服直线运动平台 — 上下位机通信协议

## 1. 物理层

| 项目 | 参数 |
|:---|:---|
| 接口 | USB 转 TTL（CH340） |
| 下位机串口 | USART1：PA9 (TX)、PA10 (RX) |
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |
| 流控 | 无 |
| 通信方式 | 上位机（PC）→ 下位机（STM32）单向控制；下位机→上位机为 ASCII 调试信息 |

> 接线注意：USB 转 TTL 的 TX 接 PA10，RX 接 PA9，GND 必须共地。

---

## 2. 帧格式

上位机发送的控制帧固定为 4 字节：

| 字节偏移 | 字段 | 长度 | 说明 |
|:---:|:---|:---:|:---|
| 0 | 帧头 | 1 | 固定 `0xAA` |
| 1 | 命令码 | 1 | 见命令总表 |
| 2 | 数据 | 1 | 速度档位 `0x01~0x0A`，或 `0x00` |
| 3 | 校验和 | 1 | `(0xAA + 命令码 + 数据) & 0xFF` |

校验和公式：


校验和 = (0xAA + 命令码 + 数据) & 0xFF

## 3. 命令总表

| 功能 | 命令码 | 数据 | 完整帧（HEX） | 校验和 |
|:---|:---:|:---:|:---|:---:|
| 正转 1 档 | `0x01` | `0x01` | `AA 01 01 AC` | `0xAC` |
| 正转 2 档 | `0x01` | `0x02` | `AA 01 02 AD` | `0xAD` |
| 正转 3 档 | `0x01` | `0x03` | `AA 01 03 AE` | `0xAE` |
| 正转 4 档 | `0x01` | `0x04` | `AA 01 04 AF` | `0xAF` |
| 正转 5 档 | `0x01` | `0x05` | `AA 01 05 B0` | `0xB0` |
| 正转 6 档 | `0x01` | `0x06` | `AA 01 06 B1` | `0xB1` |
| 正转 7 档 | `0x01` | `0x07` | `AA 01 07 B2` | `0xB2` |
| 正转 8 档 | `0x01` | `0x08` | `AA 01 08 B3` | `0xB3` |
| 正转 9 档 | `0x01` | `0x09` | `AA 01 09 B4` | `0xB4` |
| 正转 10 档 | `0x01` | `0x0A` | `AA 01 0A B5` | `0xB5` |
| 反转 1 档 | `0x02` | `0x01` | `AA 02 01 AD` | `0xAD` |
| 反转 2 档 | `0x02` | `0x02` | `AA 02 02 AE` | `0xAE` |
| 反转 3 档 | `0x02` | `0x03` | `AA 02 03 AF` | `0xAF` |
| 反转 4 档 | `0x02` | `0x04` | `AA 02 04 B0` | `0xB0` |
| 反转 5 档 | `0x02` | `0x05` | `AA 02 05 B1` | `0xB1` |
| 反转 6 档 | `0x02` | `0x06` | `AA 02 06 B2` | `0xB2` |
| 反转 7 档 | `0x02` | `0x07` | `AA 02 07 B3` | `0xB3` |
| 反转 8 档 | `0x02` | `0x08` | `AA 02 08 B4` | `0xB4` |
| 反转 9 档 | `0x02` | `0x09` | `AA 02 09 B5` | `0xB5` |
| 反转 10 档 | `0x02` | `0x0A` | `AA 02 0A B6` | `0xB6` |
| 停止 | `0x03` | `0x00` | `AA 03 00 AD` | `0xAD` |
| 急停 | `0x04` | `0x00` | `AA 04 00 AE` | `0xAE` |
| 调零 | `0x05` | `0x00` | `AA 05 00 AF` | `0xAF` |

> 注意：`0x0A` 表示第 10 档，不是换行符；发送时必须使用 HEX 模式，且不要勾选“加回车换行”。

## 4. 速度档位说明

| 档位 | 数据值 | 说明 |
|:---:|:---:|:---|
| 1 | `0x01` | 最慢 |
| 2 | `0x02` | 慢 |
| 3 | `0x03` | 较慢（自动对准固定使用） |
| 4 | `0x04` | 中慢 |
| 5 | `0x05` | 中速 |
| 6 | `0x06` | 中快 |
| 7 | `0x07` | 快 |
| 8 | `0x08` | 较快 |
| 9 | `0x09` | 很快 |
| 10 | `0x0A` | 最快 |

## 5. 下位机返回信息

下位机通过串口返回 ASCII 文本，仅用于调试和状态提示，不属于二进制控制协议。

| 返回信息 | 含义 |
|:---|:---|
| `STM32 Stepper Motor Controller Ready.` | 系统启动就绪 |
| `Forward, speed level: X` | 正转，速度档位 X |
| `Reverse, speed level: X` | 反转，速度档位 X |
| `Stop` | 停止 |
| `Emergency Stop!` | 急停 |
| `Homing start...` | 开始调零 |
| `Homing complete, position = 0` | 调零完成，位置归零 |
| `Positive limit triggered!` | 正限位触发 |
| `Negative limit triggered!` | 负限位触发 |
| `Unknown command: 0xXX` | 未知命令 |

## 6. 发送示例

使用 SSCOM、串口助手或 Python 发送时，必须选择 HEX 发送，不要附加回车换行。

| 操作 | 发送内容 |
|:---|:---|
| 正转 5 档 | `AA 01 05 B0` |
| 反转 3 档 | `AA 02 03 AF` |
| 停止 | `AA 03 00 AD` |
| 急停 | `AA 04 00 AE` |
| 调零 | `AA 05 00 AF` |
