# IO 分配表

本文档记录视觉伺服直线运动平台的电气 IO 分配、接线关系与供电方案。

---

## 1. STM32F103C8T6 引脚分配

| 引脚 | 功能 | 方向 | 说明 |
|------|------|------|------|
| PA8 | TIM1_CH1 PWM 输出 | 输出 | 脉冲信号，接 DM542 的 PUL- |
| PB5 | GPIO 输出 | 输出 | 方向控制，低电平正转，高电平反转，接 DM542 的 DIR- |
| PB10 | GPIO 输入（上拉） | 输入 | 负限位/零点光电开关，低电平触发 |
| PB11 | GPIO 输入（上拉） | 输入 | 正限位光电开关，低电平触发 |
| PA9 | USART1_TX | 输出 | 串口发送，备用调试 |
| PA10 | USART1_RX | 输入 | 串口接收，接 CH340 的 TX |
| PA13 | SWDIO | 双向 | 程序下载与调试 |
| PA14 | SWCLK | 输入 | 程序下载与调试 |
| VDD | 电源 | — | 3.3V 供电 |
| VSS | 电源 | — | 接地 |

## 2. DM542 驱动器接线

| DM542 端子 | 接到 | 说明 |
|------------|------|------|
| PUL+ | +5V | 共阳极接法 |
| PUL- | PA8 | 脉冲信号 |
| DIR+ | +5V | 共阳极接法 |
| DIR- | PB5 | 方向信号 |
| ENA+ | 悬空 | 不使能 |
| ENA- | 悬空 | 不使能 |
| VCC | +24V | 主电源正极 |
| GND | 24V GND | 主电源负极 |
| A+ | 57 步进电机 A+ | 电机 A 相 |
| A- | 57 步进电机 A- | 电机 A 相 |
| B+ | 57 步进电机 B+ | 电机 B 相 |
| B- | 57 步进电机 B- | 电机 B 相 |

**细分设置：** DM542 拨码 SW1~SW4 设置为 16 细分（具体拨码见驱动器面板表）。

## 3. 限位开关接线

| 光电开关 | 端子 | 接到 | 说明 |
|----------|------|------|------|
| 负限位/零点（左端） | VCC | +5V | 供电 |
| 负限位/零点（左端） | GND | GND | 地 |
| 负限位/零点（左端） | OUT | PB10 | 低电平触发 |
| 正限位（右端） | VCC | +5V | 供电 |
| 正限位（右端） | GND | GND | 地 |
| 正限位（右端） | OUT | PB11 | 低电平触发 |

**型号：** EE-SX674-2N，NPN 常开型。

## 4. CH340 串口模块接线

| CH340 端子 | 接到 | 说明 |
|------------|------|------|
| TX | PA10（USART1_RX） | 交叉连接 |
| RX | PA9（USART1_TX） | 交叉连接 |
| VCC | 3.3V 或 5V | 与 STM32 逻辑电平匹配，建议 3.3V |
| GND | GND | 共地 |

**通信参数：** 波特率 115200，数据位 8，停止位 1，无校验。

---

## 5. 供电分配

| 电源 | 电压 | 供给对象 | 说明 |
|------|------|----------|------|
| 220V 交流市电 | AC 220V | 24V 开关电源 | 输入 |
| 24V 开关电源 | DC 24V | DM542 驱动器主回路 | 电机驱动 |
| DC-DC 降压模块 | DC 5V | 光电开关、CH340 | 由 24V 降压 |
| STM32 板载 LDO | DC 3.3V | STM32 芯片及外围 | 由 5V 稳压 |

**共地要求：** 24V、5V、3.3V 的 GND 必须单点共地，确保信号参考电位一致。

---

## 6. 电气接线注意事项

1. 强弱电分离：24V 驱动回路使用 0.75mm² 导线，控制信号线使用 0.15mm² 导线，分开走线。
2. 信号线采用屏蔽线，屏蔽层单端接地。
3. 驱动器主回路与控制回路之间通过光耦隔离。
4. 接线端子采用插拔式接线排，便于调试更换。
5. 全部接线完成后，先进行对地绝缘测试和短路测试，确认无误后再通电。
6. 通电后先测量各电压节点：DM542 的 VCC 与 GND 应为 24V，STM32 的 3.3V 和 5V 应正常。

## 7. 接线总览

```
上位机 PC
  ├── USB 工业相机
  └── CH340 模块
        ├── TX → PA10
        ├── RX → PA9
        ├── VCC → 3.3V
        └── GND → GND

STM32F103C8T6
  ├── PA8 → DM542 PUL-
  ├── PB5 → DM542 DIR-
  ├── PB10 → 负限位/零点光电开关 OUT
  ├── PB11 → 正限位光电开关 OUT
  ├── PA13 → SWDIO
  ├── PA14 → SWCLK
  ├── VDD → 3.3V
  └── VSS → GND

DM542
  ├── PUL+ → +5V
  ├── PUL- → PA8
  ├── DIR+ → +5V
  ├── DIR- → PB5
  ├── VCC → +24V
  ├── GND → 24V GND
  └── A+/A-/B+/B- → 57 步进电机

供电
  ├── 220V AC → 24V 开关电源 → DM542
  ├── 24V → DC-DC 5V → 光电开关、CH340
  └── 5V → 3.3V LDO → STM32
```
